# Claude 巡检中转

> `astrbot_plugin_dafeiyu_claude` · v0.1.0 · [大肥鱼](https://github.com/mengbaiyoudianxian/dafeiyu) 的自写插件之一

Claude 每小时看日志，用她的 QQ 私聊主人提改法；主人回「同意

## 安装

AstrBot（4.x）后台 → 插件 → 右上角「+」→ 从链接安装，填：

```
https://github.com/mengbaiyoudianxian/astrbot_plugin_dafeiyu_claude
```

装完在插件列表里点开它的配置，按需改。平台目前只适配 aiocqhttp（NapCat / OneBot v11）。
